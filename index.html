Justifikasi Teoretis Pemilihan Model Damped Holt-Winters (φ=0.85)

Penjelasan ilmiah untuk pertanggungjawaban akademis Sistem Informasi

Mengapa Tidak Menggunakan Model Linear Biasa?

Pasca pandemi Covid-19, mobilitas masyarakat mengalami normalisasi tren. Model linier standar (Holt-Winters linier) cenderung memproyeksikan kenaikan tajam tanpa batas (over-forecasting) yang berbahaya jika dijadikan acuan kapasitas posko. Parameter peredam φ = 0.85 secara matematis meredam proyeksi kemiringan tren jangka panjang agar mendekati titik jenuh kapasitas nyata jaringan transportasi nasional.

Persamaan Matematis Damped Holt-Winters

Level   : ℓt = α(yt - st-m) + (1-α)(ℓt-1 + φbt-1)
Trend   : bt = β(ℓt - ℓt-1) + (1-β)φbt-1
Seasonal: st = γ(yt - ℓt-1 - φbt-1) + (1-γ)st-m
Forecast: ŷt+h = ℓt + ∑(φi bt) + st+h-m
